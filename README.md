# RecipeGenerator



A Java-based pantry management application that helps users keep track of the food they have at home, discover recipes they can make, monitor expiry dates, and generate shopping lists.



The project is designed using \*\*Object-Oriented Programming (OOP)\*\* principles and aims to make managing household ingredients easier while reducing unnecessary food waste.



\---



Features



Pantry Management



\-Add ingredients to your pantry

\-Remove ingredients

\-Update ingredient quantities

\-View everything currently in your pantry

\-Store expiry dates for ingredients



Recipe Suggestions



\-Store recipes and their required ingredients

\-Check which recipes can be made with the ingredients you have

\-Identify recipes that are almost possible to make

\-Show which ingredients are missing from a recipe



Shopping List



\-Generate a shopping list from missing ingredients

\-Track ingredients that need to be purchased

\-Avoid buying ingredients that are already available in the pantry



\-Expiry Tracking



\-Identify expired ingredients

\-Find ingredients that are approaching their expiry date

\-Prioritise recipes that use ingredients which are about to expire



\-Future Features



\-Meal planning

\-Nutritional information

\-Graphical user interface using JavaFX

\-Persistent storage using SQLite

\-Recipe filtering by dietary requirements

\-Automatic shopping list generation based on a meal plan

Service
